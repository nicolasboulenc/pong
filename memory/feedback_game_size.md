Don't reason around the size of this game when the user asks about applying a pattern or technique.

**Why:** This project is a deliberate stepping stone toward a more complex game. The user finds it easier to practice slightly advanced ideas on a simple codebase first.

**How to apply:** When asked "what do you think about using X here?", evaluate the idea on its own merits and tradeoffs — not on whether it's "worth it for a game this size."
